# Ahmad Syamil — Portfolio

Personal portfolio site showcasing full-stack development projects, experience, and contact information.

## Tech stack

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS

## Local development

```sh
npm i
npm run dev
```

## Build

```sh
npm run build
npm run preview
```
